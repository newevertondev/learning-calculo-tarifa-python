# Cálculo de Tarifa em Python

Programa simples desenvolvido em Python para calcular o valor a pagar de acordo com o tempo de utilização informado em minutos.

## Funcionalidades

- Receber a quantidade de minutos utilizados
- Aplicar tarifa padrão para até 100 minutos
- Calcular cobrança adicional para minutos excedentes
- Exibir o valor total a pagar

## Exemplo

Quantos minutos? 120

Valor a pagar: R$ 90.00

## Tecnologias Utilizadas

- Python

## Conceitos Praticados

- Entrada de dados
- Variáveis
- Estruturas condicionais (if/else)
- Operadores aritméticos
- Formatação de valores monetários
